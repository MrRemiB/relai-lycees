# Relai Lycées implementation contract

**Current routing override:** `ROUTING_CONTRACT.md` governs travel-time ranking, `max_travel_minutes`, IGN route geometry, provider failure/partial comparisons, assignment route verification and privacy. The original geodesic-ranking notes below describe the initial implementation only; geographic radii remain prefilters. User requested the routing change and GitHub publication.

Demo application, no official affiliation, no real teacher data. Schools nationwide real incl overseas. Synthetic teachers only, base = fictional administrative location anchored at official school coordinate, never home. Public/demo local service bound 127.0.0.1. All state in SQLite runtime/relai.sqlite3, not exposed by static routing. stdlib Python server app.py; frontend static/; official data data/schools.json envelope metadata,schools. Frontend plain ES modules vendored Leaflet + markercluster. Port default 8127 env RELAI_PORT. API JSON errors {error:string}.

School fields id UAI,name,city,postcode,address,department,academy,region,sector Public/Privé,lat/lon nullable,pathways string array,updated_at.
Teacher fields id,name synthetic 'Profil démo 0001',subjects:string[],academy,sector Public/Privé,lat,lon,base_label,capacity_hours:number,max_distance_km:number,available_from ISO date,available_until ISO date,pathways:string[],cross_academy:boolean. Hours = weekly teaching hours over continuous inclusive date interval. Note schedule/time slots unknown, prohibit any overlapping dated assignment to same teacher even spare hours (conservative collision rule disclosed). Cross-sector hard incompatible. Academy match required unless teacher.cross_academy and need allow_cross_academy true. All pathways and subject strings from metadata list. Need allow_cross_academy:boolean default false. Routing distances haversine, straight-line only. No route/time guarantee. Candidate chosen subject,pathway,sector,academy,full date availability,capacity,own mobility radius,need radius,not assigned overlapping dates. Rank distance ascending then available remaining capacity descending then id stable. Nearby unqualified excluded, never offered. Human simulated validation only. No employment automation.
